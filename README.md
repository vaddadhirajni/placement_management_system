# Placement Management System

A Python Tkinter + MySQL based Placement Management System.

### Features:
- Students Management - Add, View, Delete Students
- Companies Management - Add Companies with Min CGPA criteria
- Applications - Apply for jobs & Check Eligibility
- Report Dashboard - Total Students, Placed Applications

### Tech Stack:
- Python (Tkinter)
- MySQL Workbench
- Python MySQL Connector
